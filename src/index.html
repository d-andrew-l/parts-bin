Upgrade optimizer

Checks every build against the parts marked Available (never ones marked Sell, sold, or in use elsewhere) and lists only changes that are compatible and measurably better: more RAM or dual channel, a faster CPU on the same socket, an SSD where there's none, capacity for free slots, a faster GPU that fits the case and the power supply. "Worth buying" lists upgrades you don't have parts for yet.

      History

        Paste a hardware report

        On Linux run inxi -Fxz (install with sudo apt install inxi) and paste the output. On Windows, CPU-Z → Tools → Save Report as .TXT, then open it here. A model name in any text works too.

        Review import

        Untick anything you don't want. Platform details (socket, RAM type, slots) are filled in where the report had them.

          Welcome to Parts Bin

          Keep track of every part on the shelf and in your machines, see what's in use, and let the optimizer tell you when a spare would make a build better. Each machine gets its own planet or moon, picked from its name. Everything stays on this computer.

          Settings

          Keyboard

          / or Ctrl F search · Ctrl N new part · Ctrl Z undo · Ctrl Y redo · 1 2 3 switch views · Esc close or clear

          My boards

          Boards, single-board computers and modules you added with “Not here?”. The built-in list has boards from PlatformIO.

            About

            Open source under the MIT license. No accounts, no telemetry: your data never leaves this computer unless you export it.

            Data & backups

            Every change saves instantly. A snapshot is kept every 10 minutes of editing (newest 40). Restoring keeps a snapshot of the current state first, so it can be undone.

              Trash

              Deleted parts stay here for 30 days.
