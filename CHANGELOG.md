# Changelog

## 2.0.0 (unreleased)

First public release.

- Scan this PC, or paste `inxi -Fxz` / CPU-Z reports; review parts before importing.
- Open parts database (129 CPUs, 40 GPUs) with an open CPU score; no proprietary benchmark data.
- Optimizer: power-supply headroom, GPU fit (low-profile, length, power), cooler and BIOS warnings,
  "worth buying" suggestions with eBay sold-price links, multi-drive lots.
- Dev Board, SBC and Module part types with 1,425 boards from PlatformIO's open board list, a
  "Not here? Add it to my boards" button for anything missing, and electronics-project builds.
- Each machine gets a planet or moon from its name (29 worlds), with a picker and live preview.
- Buy/sell tracking with spend and profit, photos, test log, drive health, quantities, storage locations.
- QR labels (Avery 5160 / 5163) and webcam label scanning; PDF inventory report; CSV import/export.
- Undo/redo, 30-day trash, snapshot restore, welcome screen with sample homelab, settings
  (theme, text size, reduced motion, currency, updates).
- Installers for Windows, macOS and Linux with automatic updates from GitHub Releases.
- Data from 1.x upgrades automatically; the original file is kept in backups.

## 1.0.0

Private version: inventory, builds, basic optimizer, pixel-art redesign.
